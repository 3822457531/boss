# 2026-09-24 FAQ 回答自由度 + 发送节奏

## 1. FAQ 不直出原文
- 配置：`reply.faq_freedom`（0～3）
  - 0：仍用模板套事实原文
  - 1～3：选题后用 LLM 按事实改写，意思不变、措辞每次不同
- 管理台「发送节奏」可调

## 2. 发送节奏：两道闸（不是三套钟）

一个人怎么走完：

```
读消息/打招呼 → ①发出前停顿 → 真正发送 → ②换人歇一歇 → 下一个人
```

| 闸 | 何时生效 | 配置 |
|----|----------|------|
| ① 发出前停顿 | 马上要 `boss send` 时（字越多停越久） | `rate_limit.typing_delay_*` |
| ② 换人歇一歇 | 处理完当前人再接下一位 | `rate_limit.send_interval_*` |

跳过/失败：不做①，②只短歇 `skip_gap_sec`（默认 3 秒），不白等满间隔。  
自动回复与打招呼共用同一套；日志分别写「发出前停顿…」「换人歇一歇…」「换人短歇…」。
