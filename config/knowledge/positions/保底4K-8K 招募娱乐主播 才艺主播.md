## 技术栈要求
我们主要用 PHP 7/8，搭配 MySQL、Redis、Nginx，框架看项目组，常见是 Laravel 或 ThinkPHP。希望你熟悉 LNMP 环境，会 Git 协作。具体版本和工具入职后会按团队规范来。

## PHP 框架经验
希望至少熟悉一种主流 PHP 框架，比如 Laravel、ThinkPHP、Yii 等，有实际项目落地经验最好。没有用过特定框架也没关系，基础扎实能快速上手就行。面试会聊一下你熟悉的框架和实现思路。

## 项目经验要求
最好有 1-3 年 PHP 开发经验，参与过完整项目周期，能独立负责模块开发。做过商城、管理系统、API 接口等都可以聊。应届生如果有扎实的项目或实习经历也欢迎投递。

## 是否接受应届生
接受优秀应届生，但需要有一定 PHP 基础，比如做过课程设计、个人项目或实习。我们会看学习能力和代码习惯，入职有导师带。具体定级和薪资面议。

## 面试流程
一般先电话或视频初筛，然后技术面试，可能会聊项目、写点代码或在线笔试，最后 HR 沟通薪资和到岗时间。流程大概 1-2 轮技术面，具体安排以招聘同事通知为准。

## 团队情况
PHP 团队和前端、测试、产品一起协作，规模看项目组，一般十几人到几十人。技术氛围比较务实，有代码评审和分享。具体团队分工面试时可以详细聊。

## 数据库要求
需要熟悉 MySQL 常用操作，了解索引、事务和基本优化，会写复杂 SQL。有 Redis 缓存使用经验是加分项。高并发场景经验不是硬性，但会优先考虑。

## 晋升空间
技术方向可以从初级到高级、资深、技术专家，也有管理方向如组长、主管。晋升看能力和绩效，一般每年有评估机会。具体通道和标准入职后会沟通。
